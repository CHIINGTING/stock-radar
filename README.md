# Stock Radar

一套針對台灣股市（上市 TSE / 上櫃 TPEX）設計的個人即時技術分析工具。
結合**即時行情**、**盤中多時間框 K 線**、**委買賣單流**與**歷史技術指標**，自動計算評分並直接給出交易建議。

系統分成兩個定位清楚的工具：

| 工具 | 定位 | 時間尺度 | 回答的問題 |
|---|---|---|---|
| **Radar（當沖）** | 盤中當沖、停損停利 | 3 / 5 / 15 分鐘 | 今天能不能做？方向對不對？是不是突破點？主力進場沒？ |
| **Scanner（掃描器）** | 波段選股（1～4 週） | 日線 | 未來幾週有沒有機會？現在是剛起漲還是末升段？ |

另有 **Portfolio（持倉管理）** 與 **Watchlist（自選股）** 兩個輔助頁面。

## 安裝

**需求：** Go 1.21 以上（本專案於 Go 1.26 開發）

```bash
git clone <repository-url>
cd stock-radar

go mod tidy
make build
```

## 啟動

```bash
make run
```

或不透過 make：

```bash
go run ./cmd/server
```

啟動後開啟瀏覽器前往：**http://localhost:8080**

> 首次啟動會預先載入所有自選股與持股的即時報價，約需 5～15 秒。
> 啟動後會有一個背景輪詢持續更新報價，並**累積委買賣單流的近 15 分鐘時序**——
> 因此 Radar 的「買賣比趨勢」需要伺服器跑一小段時間（約 5～15 分鐘）才會完整顯示，剛啟動時會顯示「累積中…」。

## stocks.yaml — 設定檔說明

所有設定集中在專案根目錄的 `stocks.yaml`，**不需要重新編譯**，修改後重新整理頁面即可生效。

### 完整範例

```yaml
# 報價快取更新間隔（秒）
refresh_seconds: 3

# 評分閾值（可依個人習慣調整）
strategy:
  buy_score: 80      # 達到此分數顯示 BUY
  watch_score: 60    # 達到此分數顯示 WATCH

# 持股（Portfolio）
positions:
  - code: "2337"
    name: "旺宏"
    market: "TW"      # 上市；上櫃填 "TWO"，不填則自動偵測
    entry: 173.5      # 買進成本（元）
    shares: 1000      # 持股張數（1 張 = 1000 股）

  - code: "5483"
    name: "中美晶"
    market: "TWO"     # 上櫃 TPEX
    entry: 165
    shares: 2000

# 自選觀察股（Watchlist）— Radar 與 Scanner 都掃這份清單
watchlist:
  - code: "2303"
    name: "聯電"

  - code: "8299"
    name: "群聯"
    market: "TWO"     # 上櫃 TPEX

  # 處置股 / 注意股可標記，Scanner 會顯示倒數與風險
  - code: "2330"
    name: "台積電"
    warn: "處置股"
    warn_start: "2026-05-28"
    warn_end:   "2026-06-10"
```

### 欄位說明

| 欄位 | 適用 | 必填 | 說明 |
|---|---|---|---|
| `code` | 全部 | ✅ | 股票代號（四位數，不含 .TW / .TWO） |
| `name` | 全部 | ✅ | 股票名稱（僅供顯示用） |
| `market` | 全部 | ⬜ | `"TW"`=上市 / `"TWO"`=上櫃 / **不填=自動偵測**。詳見 [.TW / .TWO 說明](#yahoo-tw--two-說明) |
| `entry` | 持股 | ✅ | 買進成本，單位：元 |
| `shares` | 持股 | ✅ | 持股張數，1 張 = 1000 股 |
| `warn` | 自選 | ⬜ | `"處置股"` / `"注意股"`（不填=正常） |
| `warn_start` | 自選 | ⬜ | 處置/注意開始日，格式 `YYYY-MM-DD` |
| `warn_end` | 自選 | ⬜ | 預計解除日，用於倒數顯示 |

> **建議**：上櫃股票務必填 `market: "TWO"`。雖然系統會自動偵測，但明確指定可避免偶發的探測延遲與抓錯市場。

## Radar — 當沖工具

Radar 是**盤中當沖**的核心。它不只是把技術指標數字攤給你看，而是直接回答四個當沖最關鍵的問題：

```
今天能不能做？   →  Action + 評分
方向對不對？     →  15 分趨勢燈號
現在是不是突破點？→  3 分趨勢燈號
主力有沒有進場？ →  買賣單流趨勢 + 量能型態
```

### 為什麼要看三個時間框？

實際當沖最常踩的坑是「**3 分線看多、15 分線看空**」——3 分鐘剛爆量你就追，結果只是大框下跌中的反彈。
所以 Radar 把三個時間框各自分工：

| 時間框 | 角色 | 回答 | 判定方式 | 權重 |
|---|---|---|---|---|
| **15 分鐘** | 決定**方向** | 今天做不做、是多是空 | MA5 vs MA20 → 偏多 / 偏空 | 30% |
| **5 分鐘** | 找**進場點** | 什麼時候進 | MA5 vs MA20 → 偏多 / 偏空 | 15% |
| **3 分鐘** | 確認**點火** | 主力是否剛進場 | 爆量(≥2x) + 突破前高 → 突破 | 10% |

剩下的權重給單流：

| 維度 | 回答 | 權重 |
|---|---|---|
| **單量趨勢** | 量能是主流股還是短線炒作 | 25% |
| **買賣比** | 委買賣單流是增強還是衰退 | 20% |

> 五項加權後得到 0～100 的評分。

### 燈號

Dashboard 上每檔股票顯示三顆燈，一眼看出三框是否同向：

| 燈號 | 意義 |
|---|---|
| 🟢 | 偏多（Bullish）|
| 🔴 | 偏空（Bearish）|
| 🟡 | 中性（Neutral）|
| 🚀 | 突破（Breakout，僅 3 分框）|

理想的進場是 **🟢🟢🚀**（方向多、進場點到、剛點火）。

### 進場規則（BUY 閘門）

> **不要因為 3 分鐘爆量就 BUY。**

Radar 有一條硬規則：**必須三框同時成立才允許 BUY**：

```
15 分偏多  ∧  5 分偏多  ∧  3 分突破   →  才可能 BUY
```

任何一框不成立，無論評分多高，**最高只到 WATCH**。
這條閘門是刻意設計的——它擋掉「短線單獨爆量、大框其實向下」的假突破。

| Action | 觸發條件 |
|---|---|
| `STRONG BUY` | 三框成立 + 評分 ≥ `buy_score`+7 + 買盤增強 |
| `BUY` | 三框成立 + 評分 ≥ `buy_score` |
| `WATCH` | 三框成立但分數不足／短框已發動但大框未確認 |
| `WAIT` | 訊號不足，按兵不動 |
| `REDUCE` | 15 分轉空且短框無支撐（持有者宜減碼）|
| `STOP LOSS` | 15 分、5 分皆空且買盤衰退（持有者宜出場）|

### 範例

```
旺宏
15分: Bullish   5分: Bullish   3分: Breakout
買盤: 增強
Score: 92  →  STRONG BUY     ← 三框全亮 + 買盤增強
```

```
旺宏
15分: Bearish   5分: Bullish   3分: Breakout
Score: 55  →  WATCH          ← 短框發動，但 15 分偏空 → 閘門關閉，不 BUY
```

### 量能分析（3 / 5 / 15 分分開看）

Radar **不只看總量**，而是分別計算三個時間框的量比（當前 K 棒量 ÷ 該時間框近 20 根均量），藉此分辨資金性質：

```
Volume3m = 3.5x   Volume5m = 2.8x   Volume15m = 2.5x   →  主流股（量能全面放大、資金持續）
Volume3m = 3.5x   Volume5m = 1.1x   Volume15m = 0.8x   →  短線炒作（只有 3 分爆量、非主流資金）
```

- **主流股**：3 / 5 / 15 分量比皆 ≥ 1.5x
- **短線炒作**：3 分 ≥ 2.0x 但 15 分 < 1.0x

### 買賣單流分析（近 15 分鐘趨勢）

委買賣不是只看「現在買一掛很多」的單一快照，而是**追蹤近 15 分鐘的變化**：

```
09:00  買賣比 1.2
09:05  買賣比 1.8
09:10  買賣比 2.4
09:15  買賣比 3.1
        ↓
判定：買盤持續增強
```

系統對近 15 分鐘的買賣比序列做線性回歸，依斜率判定 **增強 / 持平 / 衰退**，並在 Dashboard 上以 sparkline 小圖呈現。少於 3 個樣本（剛啟動）時顯示「持平／累積中」。

> 資料來源：委買賣量取自 TWSE MIS 的前五檔委買/委賣總量，買賣比 = 委買 ÷ 委賣。

## Scanner — 掃描器（波段）

**用途：** 在眾多自選股中，找出未來 1～4 週（約 20 個交易日）有機會的標的。按技術評分由高到低排序。

**回答：** 未來幾週有沒有機會？現在是剛起漲還是末升段？

**核心指標**（與 Radar 不同，Scanner 看的是日線波段）：

- **MA60 / MA120 趨勢排列**（多頭結構）
- **60 / 120 日新高、突破整理區**
- **相對強度 RS**（個股 40 日報酬 ÷ 自選股平均）
- **族群強弱**（同族群資金流入 / 流出）
- **台股漲跌停 / 連板 / 處置注意股**分析
- **Weinstein 市場階段**：底部整理 → 突破初期 → 主升段中期 → 主升段末期 → 出貨風險

> 「突破初期」是波段最佳進場點；「主升段末期 / 出貨風險」則提醒避免追高。

## Portfolio — 持倉管理

**用途：** 針對已持有的股票，直接告訴你現在該怎麼做，而不是秀一堆數字讓你自己猜。

**顯示：** 成本價、現價、損益%、停損價、目標一/二、風報比，以及**建議動作 + 完整中文交易建議**。

範例：

```
旺宏    成本 173.5    現價 170.0
Action: STOP LOSS
原因：跌破 MA20、買盤衰退、量能下降
```

持倉 Action：`STRONG BUY`（加碼）/ `HOLD`（續抱）/ `REDUCE`（減碼）/ `TAKE PROFIT`（獲利了結）/ `STOP LOSS`（停損）/ `SELL`（出清）。
詳見 [Action 定義總表](#action-定義總表) 與 [停損邏輯](#停損邏輯)。

## Action 定義總表

不同頁面因目的不同，Action 略有差異：

### Radar（當沖，分鐘級）

| Action | 中文 | 意義 |
|---|---|---|
| `STRONG BUY` | 強力進場 | 三框全亮 + 買盤增強，當沖最佳訊號 |
| `BUY` | 可進場 | 三框成立、評分達標 |
| `WATCH` | 觀察 | 有訊號但閘門未全開，等確認 |
| `WAIT` | 等待 | 訊號不足，不動作 |
| `REDUCE` | 減碼 | 方向轉空，持有者宜減碼 |
| `STOP LOSS` | 停損 | 方向與買盤俱弱，持有者宜出場 |

### Watchlist（日線進場）

| Action | 評分（預設） | 意義 |
|---|---|---|
| `STRONG BUY` | ≥ 95 | 技術面極強勢，有量有價 |
| `BUY` | ≥ 80 | 多項指標轉多，可考慮進場 |
| `WATCH` | ≥ 60 | 訊號轉強中，持續關注 |
| `WAIT` | < 60 | 技術面不佳，等更好時機 |

### Portfolio（持倉）

| Action | 中文 | 意義 |
|---|---|---|
| `STRONG BUY` | 可加碼 | 技術面全面轉強且量增 |
| `HOLD` | 續抱 | 趨勢健康，持有至目標一 |
| `REDUCE` | 減碼 | 已獲利且超買，出脫 1/3～1/2 |
| `TAKE PROFIT` | 獲利了結 | 已達目標一，分批出場 |
| `STOP LOSS` | 停損 | 技術面轉弱，停損價附近出場，勿攤平 |
| `SELL` | 出清 | 硬觸停損且多重崩潰，立即出場 |

> **BUY / WATCH / HOLD 的差別**：
> `BUY` = 進場訊號（你目前**沒有**部位，可以買）；
> `WATCH` = 還不夠成立，**先別買**，加入觀察等確認；
> `HOLD` = 你**已經持有**，趨勢沒壞，續抱別亂動。
> 三者用在不同情境，別混用。

## 停損邏輯

Portfolio 的停損價取以下兩者的**較高（較緊）值**：

1. 成本 × 95%（固定 5% 以下）
2. MA20 × 99.5%（MA20 正下方 0.5%）

**例：** 成本 173.5、MA20 = 170.0
- 固定停損：173.5 × 95% = 164.83
- MA20 停損：170.0 × 99.5% = 169.15（較高、較緊）→ **採用 169.15**

MA20 是中短期多空分水嶺，跌破通常代表趨勢轉弱，因此 MA20 停損比固定停損更早保護你。

目標價以風險為基礎：

```
風險 Risk = 成本 - 停損價
目標一    = 成本 + Risk × 1.5   （1:1.5 風報比）
目標二    = 成本 + Risk × 3.0   （1:3.0 風報比）
```

> **停損永遠優先於任何技術訊號。** 即使系統顯示 HOLD，只要觸及停損價，務必執行，不要攤平、不要等隔天。

## Yahoo .TW / .TWO 說明

台股在 Yahoo Finance 的代號規則：

| 市場 | 後綴 | 範例 |
|---|---|---|
| 上市（TSE） | `.TW` | `2337.TW`（旺宏）、`2408.TW`（南亞科）|
| 上櫃（TPEX） | `.TWO` | `5483.TWO`（中美晶）、`8299.TWO`（群聯）|

系統內部用 `YahooSymbol(code, market)` 組出正確代號：

- `stocks.yaml` 填 `market: "TW"` → 只抓 `code.TW`
- 填 `market: "TWO"` → 只抓 `code.TWO`
- **不填** → 自動先試 `.TW`、失敗再試 `.TWO`，並快取結果

即時報價（TWSE MIS）也用相同對應：`TW → tse`、`TWO → otc`。

> **若均線顯示「-」**：代表 Yahoo 暫時抓不到該股歷史 K（常見於上櫃股未指定 market、或剛上市/量極低）。
> 解法：在 `stocks.yaml` 明確填上正確的 `market`。即時報價不受影響。

## 常見問題

**Q：Radar 的三個燈號都灰灰的 / 量比顯示 0？**

A：多半是**非交易時段**（盤中為週一～五 09:00～13:30）。收盤後 Yahoo 盤中 K 線無即時更新，量比與買賣比趨勢會停止變化、`closed` 標記為已收盤。盤中時段一切會正常填值。

---

**Q：買賣比趨勢一直顯示「累積中…」？**

A：買賣比趨勢需要**近 15 分鐘的時序**，伺服器啟動後會背景輪詢逐步累積樣本，至少 3 筆才會給方向。剛啟動或剛切到某檔股票時屬正常，跑一段時間就會出現 sparkline 與增強/衰退判定。

---

**Q：為什麼 3 分爆量、評分也不低，卻只顯示 WATCH 不給 BUY？**

A：這是**刻意的 BUY 閘門**。Radar 要求 `15分偏多 ∧ 5分偏多 ∧ 3分突破` 三者同時成立才放行 BUY。若 15 分或 5 分不同向，代表大框方向不利，3 分的爆量很可能只是反彈——此時最高只給 WATCH，避免你追在假突破上。

---

**Q：上櫃股票抓不到均線 / 歷史資料？**

A：在 `stocks.yaml` 為該股加上 `market: "TWO"`。系統雖會自動偵測，但明確指定最穩。詳見 [.TW / .TWO 說明](#yahoo-tw--two-說明)。

---

**Q：如何新增持股 / 觀察股？**

A：編輯 `stocks.yaml` 的 `positions` 或 `watchlist` 區塊新增一筆，存檔後在瀏覽器點「重新整理」即生效，**不需重啟伺服器**：

```yaml
positions:
  - code: "2330"
    name: "台積電"
    market: "TW"
    entry: 950.0
    shares: 1

watchlist:
  - code: "3008"
    name: "大立光"
```

---

**Q：評分盤中跳動很大正常嗎？**

A：正常。評分是**即時快照**，隨股價、量能、買賣盤即時變化。**分數的趨勢（持續上升或下降）比單一數字更有參考價值**。

---

**Q：停損價怎麼算出來的？**

A：取「成本 × 95%」與「MA20 × 99.5%」的較高值。詳見 [停損邏輯](#停損邏輯)。
