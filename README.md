# Stock Radar

一套針對台灣股市（上市 TSE / 上櫃 TPEX）設計的個人即時技術分析工具。
結合即時行情、歷史 K 線與量能指標，自動計算技術評分，並直接給出交易建議。

**適合用途：**

- 盤中當沖輔助：快速掃描強勢股與量能異動
- 持股管理（Portfolio）：自動計算停損、目標價，給出「續抱 / 停損 / 獲利了結」建議
- 觀察股追蹤（Watchlist）：監控多檔自選股的技術訊號
- 技術分析：均線排列、KDJ、RSI、量比、買賣比綜合評分
- 停損停利建議：根據技術面自動計算停損價、目標一、目標二、風險報酬比

## 安裝

**需求：** Go 1.21 以上

```bash
git clone <repository-url>
cd stock-radar

go mod tidy
make build
```

## 啟動

```bash
make run
```

或不透過 make：

```bash
go run ./cmd/server
```

啟動後開啟瀏覽器前往：**http://localhost:8080**

> 首次啟動會預先載入所有自選股與持股的即時報價，約需 5～15 秒。
> 之後每 60 秒自動背景更新，頁面會即時反映最新資料。

## stocks.yaml — 設定檔說明

所有設定集中在專案根目錄的 `stocks.yaml`，不需要重新編譯，修改後重新整理頁面即可生效。

### 完整範例

```yaml
# 快取更新間隔（秒）
refresh_seconds: 3

# 評分閾值（可依個人習慣調整）
strategy:
  buy_score: 80      # 達到此分數顯示 BUY
  watch_score: 60    # 達到此分數顯示 WATCH

# 持股（Portfolio）
positions:
  - code: "5483"
    name: "中美晶"
    entry: 165        # 買進成本（元）
    shares: 2000      # 持股張數（1張 = 1000股）

  - code: "2337"
    name: "旺宏"
    entry: 171.5
    shares: 1000

# 自選觀察股（Watchlist）
watchlist:
  - code: "2408"
    name: "南亞科"

  - code: "2303"
    name: "聯電"

  - code: "2330"
    name: "台積電"
```

### 欄位說明

| 欄位 | 必填 | 說明 |
|---|---|---|
| `code` | ✅ | 股票代號（四位數，不含 .TW / .TWO） |
| `name` | ✅ | 股票名稱（僅供顯示用） |
| `entry` | ✅（持股） | 買進成本，單位：元 |
| `shares` | ✅（持股） | 持股張數，1 張 = 1000 股 |

**上市（TSE）vs 上櫃（TPEX）**：只需填入代號，系統會自動判斷。
例如 `2330`（台積電，上市）或 `5483`（中美晶，上櫃）均可正確識別。

## Dashboard 三頁說明

### 掃描器（Market Scanner）

**用途：** 在眾多自選股中，快速找出最具潛力的機會。按技術評分由高到低排序，讓最強勢的股票排在最前面。

**顯示欄位：**

| 欄位 | 說明 |
|---|---|
| 評分 | 綜合技術評分（通常介於 -50 到 150 分之間） |
| 量比 | 今日成交量 ÷ 20 日均量。> 2x 代表爆量 |
| 量價型態 | 價漲量增 / 價漲量縮 / 價跌量增 / 價跌量縮 |
| 大單 | 量比 ≥ 2x 時標示，代表主力或大戶介入 |
| 買賣比 | 委買總量 ÷ 委賣總量。> 1.5 代表買盤積極 |
| 建議 | STRONG BUY / BUY / WATCH / WAIT |

> **使用情境**：盤中每隔幾分鐘看一眼掃描器，找出評分突然上升、出現大單或買賣比飆高的個股，再進一步分析是否進場。

---

### 持倉管理（Portfolio）

**用途：** 針對已持有的股票，直接告訴你現在應該怎麼做，而不只是秀出 KDJ 數字讓你自己猜。

**顯示內容：**

| 欄位 | 說明 |
|---|---|
| 成本 | 買進價格（來自 stocks.yaml 的 entry） |
| 現價 | 即時成交價 |
| 損益% | (現價 - 成本) ÷ 成本 × 100% |
| 建議動作 | STRONG BUY / HOLD / REDUCE / TAKE PROFIT / STOP LOSS / SELL |
| 交易建議 | 完整中文說明，例如「建議停損。跌破 MA20，KDJ 死亡交叉，請於停損價 164.40 出場」 |
| 停損價 | 技術面計算的出場參考價 |
| 目標一 | 第一獲利目標（風報比 1:1.5） |
| 目標二 | 第二獲利目標（風報比 1:3.0） |
| 風報比 | 風險報酬比，數字越高代表潛在獲利空間越大 |

**持倉 Actions 說明：**

| Action | 中文 | 意義 |
|---|---|---|
| `STRONG BUY` | 可加碼 | 技術面全面轉強且量增，現有部位可考慮加碼 |
| `HOLD` | 續抱 | 趨勢健康，繼續持有至目標一 |
| `REDUCE` | 減碼 | 已有獲利且指標超買，建議先出脫 1/3～1/2 持股 |
| `TAKE PROFIT` | 獲利了結 | 已達目標一，建議分批出場鎖定獲利 |
| `STOP LOSS` | 停損 | 技術面轉弱，建議在停損價附近出場，勿攤平 |
| `SELL` | 出清 | 已跌破停損且多重技術崩潰，建議立即出場 |

> **停損的計算邏輯：**
> 系統取「成本 × 95%（固定 5% 下方）」與「MA20 × 99.5%（MA20 正下方）」兩者中**較高（較緊）**的數字作為停損價。
> MA20 在技術上代表多空分水嶺，跌破 MA20 通常意味中短期趨勢已轉弱。

---

### 自選股（Watchlist）

**用途：** 快速瀏覽全部觀察股的技術概況，找到值得深入研究的標的。

**顯示欄位：** 代號、名稱、現價、漲跌、MA5、MA20、RSI14、技術評分、建議

**自選股 Actions 說明：**

| Action | 評分（預設閾值） | 意義 |
|---|---|---|
| `STRONG BUY` | ≥ 95 | 技術面極強勢，有量有價，短線進場訊號 |
| `BUY` | ≥ 80 | 多項指標轉多，可考慮進場 |
| `WATCH` | ≥ 60 | 訊號轉強中，持續關注，等待確認 |
| `WAIT` | < 60 | 目前技術面不佳，等待更好的進場時機 |

> 閾值可在 `stocks.yaml` 中的 `strategy.buy_score` 和 `strategy.watch_score` 調整。
> 點選任一列可在頁面下方看到完整技術分析詳情。

## 評分系統詳解

系統從多個維度對每支股票進行評分，最終加總得出技術評分。

### 均線（Moving Average）

| 條件 | 分數 | 說明 |
|---|---|---|
| 股價站上 MA5 | +10 | 短線動能正面 |
| 股價站上 MA20 | +15 | 中期多空分水嶺 |
| 股價站上 MA60 | +20 | 長期趨勢向上 |
| MA5 > MA20 | +10 | 短均線在長均線上方，多頭排列 |
| MA20 > MA60 | +10 | 中期趨勢優於長期趨勢 |

三線全站上且多頭排列（均線滿分）= **65 分**

### KDJ 隨機指標

| 條件 | 分數 | 說明 |
|---|---|---|
| K < 30 且 D < 30（超賣） | +15 | 短線跌深，反彈機率提升 |
| K > D 且 J > K（黃金交叉） | +10 | KDJ 出現向上交叉，動能轉多 |
| K > 80 且 D > 80（超買） | -10 | 短線漲幅已大，追高風險升高 |

> K、D 值落在 0～100 之間；J 值可超過 100 或低於 0，代表極度超買或超賣。

### RSI 相對強弱指標（14 日）

| 條件 | 分數 | 說明 |
|---|---|---|
| RSI < 30（超賣） | +15 | 跌深反彈機會 |
| RSI > 70（超買） | -10 | 短線過熱，注意回檔風險 |

> RSI 在 50 附近代表多空平衡；持續在 50 以上屬強勢；持續在 50 以下屬弱勢。

### 盤中位置

| 條件 | 分數 | 說明 |
|---|---|---|
| 股價 > 開盤價 | +5 | 今日買盤主動 |
| 股價 > 今日中間價 | +5 | 位於日內高點附近 |

### 量能分析（Volume）

| 條件 | 分數 | 說明 |
|---|---|---|
| 價漲量增（量比 ≥ 1.2x） | +15 | 多方主動，買盤積極 |
| 大單介入（量比 ≥ 2x，且漲） | +10 | 法人或主力買進 |
| 買賣比 > 1.5 | +10 | 委買大於委賣，買盤排隊 |
| 價漲量縮（量比 < 0.8x） | +5 | 漲但量不足，需觀察是否持續 |
| 價跌量縮（量比 < 0.8x） | -5 | 跌但量縮，殺盤力道不大 |
| 大單賣出（量比 ≥ 2x，且跌） | -5 | 大戶可能在出貨 |
| 賣壓偏重（買賣比 < 0.67） | -10 | 委賣遠大於委買，賣壓明顯 |
| 價跌量增（量比 ≥ 1.2x） | -15 | 空方主動，殺盤力道強 |

## 如何解讀 BUY / WATCH / HOLD / STOP LOSS

### BUY — 可以考慮買進

看到 `BUY` 代表多項技術指標同時轉多，系統認為短中期進場勝率較高。
**但 BUY 不等於保證獲利**，建議搭配以下原則：

1. **確認量能**：量比是否 ≥ 1.2x（量價配合），無量的上漲較脆弱
2. **設好停損**：進場前先確認停損位置，通常在 MA20 下方
3. **控制倉位**：單筆不超過總資金的 20%
4. **避開開盤前 15 分鐘**：台股開盤初期波動大，等方向確認再進場

`STRONG BUY` 是更強版本，代表技術評分極高且有量能配合，但仍需嚴守停損。

---

### WATCH — 持續觀察，等待訊號確認

看到 `WATCH` 代表技術面**開始轉多但還未確認**，此時進場略嫌早。
等待以下任一訊號出現再決定：

- 股價突破近期整理平台（向上突破前高）
- 量比放大至 1.5x 以上
- KDJ 出現黃金交叉
- 次日開盤站上昨日高點

**正確用法**：加入觀察清單，設定價格提醒，不要因為「感覺要漲」就衝動進場。

---

### HOLD — 續抱，不急著動作

針對**已持有的股票**，看到 `HOLD` 代表：

- 股價仍在 MA20 之上，多頭趨勢未破壞
- KDJ、RSI 尚未出現嚴重超買或轉弱訊號
- 目前沒有技術理由出場

**正確做法**：繼續持有，但要隨時盯緊停損位置。
若股價跌近停損線，務必執行出場，不要因為「系統說 HOLD」而猶豫——**停損永遠優先於任何技術訊號**。

---

### STOP LOSS — 執行停損，立刻出場

看到 `STOP LOSS` 代表系統偵測到以下兩項以上的技術警示同時出現：

- 股價跌破 MA20（中期趨勢轉弱）
- KDJ 出現死亡交叉（動能轉空）
- RSI 跌至 40 以下（相對弱勢）
- 量比放大且股價下跌（空方主動賣出）

**執行步驟：**

1. 查看持倉卡片上顯示的「停損價」
2. 若股價已在停損價附近或以下，以市價或略低於停損價的限價掛賣
3. **不要攤平，不要等隔天開盤**
4. 出場後等待訊號重新出現再考慮是否回補

`SELL`（出清）是更嚴重的警示，代表股價已**硬觸停損**且多項指標同時崩潰，必須立即出場。

---

### TAKE PROFIT — 獲利了結

當持股達到目標一且出現超買訊號時觸發。

**建議的分批出場方式：**

1. 到達目標一：出脫 50% 持股，保留另一半等目標二
2. 到達目標二：出清剩餘持股
3. 若想繼續持有：將停損移至成本以上（「移動停損」），保護已實現獲利

`REDUCE`（減碼）代表雖未到目標一，但已有一定獲利且出現超買，建議先出脫部分部位，
鎖定部分利潤，避免全部回吐。

## 常見問題

**Q：啟動後為什麼看不到股票報價？**

A：有以下幾種可能：
- 非台股交易時間（週一至週五 09:00～13:30）時，TWSE 回傳的是昨日收盤價，屬正常現象
- 股票代號填錯（例如填了 `02330` 而非 `2330`）
- 網路無法連線至 TWSE API（`mis.twse.com.tw`），確認防火牆或 VPN 設定

---

**Q：均線顯示「-」，技術評分偏低？**

A：均線需要歷史 K 線資料（從 Yahoo Finance 取得）。Yahoo Finance 對台股的代號規則：
- 上市股票（TSE）：代號加 `.TW`，例如 `2330.TW`
- 上櫃股票（TPEX）：代號加 `.TWO`，例如 `5483.TWO`

系統會自動嘗試兩種格式。若仍失敗，可能是 Yahoo Finance 暫時無該股票資料（常見於剛上市或成交量極低的股票）。均線顯示「-」僅代表歷史資料暫時無法取得，即時報價仍然正常運作。

---

**Q：如何新增持股？**

A：編輯 `stocks.yaml`，在 `positions` 區塊新增一筆：

```yaml
positions:
  - code: "2330"
    name: "台積電"
    entry: 950.0    # 你的買進成本
    shares: 1       # 持股張數
```

儲存後，在瀏覽器點「重新整理」，系統即自動載入新的持股資料，**不需要重新啟動伺服器**。

---

**Q：如何新增觀察股？**

A：在 `stocks.yaml` 的 `watchlist` 區塊新增：

```yaml
watchlist:
  - code: "3008"
    name: "大立光"
```

儲存後點「重新整理」即生效。

---

**Q：評分突然變很高或很低是正常的嗎？**

A：正常。技術評分是**即時快照**，反映當下各指標的狀態。盤中隨著股價波動，分數會跟著變化。常見情況：

- 開盤急漲後量縮 → 分數從高處下降（價漲量縮）
- KDJ 黃金交叉觸發 → 分數瞬間 +10
- 跌破 MA20 → 分數可能瞬間 -15 以上

分數的**趨勢**（持續上升或下降）比單一時間點的數字更有參考價值。

---

**Q：停損價怎麼算出來的？**

A：取以下兩個數字的**較高（較緊）值**：

1. 成本 × 95%（固定 5% 以下）
2. MA20 × 99.5%（MA20 正下方 0.5%）

**例：** 成本 171.5，MA20 = 170.0
- 固定停損：171.5 × 95% = 162.93
- MA20 停損：170.0 × 99.5% = 169.15（較高，較緊）

取較高者 → **停損價 = 169.15**

MA20 的停損比固定停損更緊，因為跌破 MA20 通常意味趨勢已轉弱，早點出場可以少虧。

---

**Q：目標一和目標二怎麼計算？**

A：以風險為基礎（Risk-Based Targets）：

```
風險（Risk）= 成本 - 停損價
目標一     = 成本 + Risk × 1.5  （1:1.5 風報比）
目標二     = 成本 + Risk × 3.0  （1:3.0 風報比）
```

**例：** 成本 171.5，停損 169.15，Risk = 2.35
- 目標一：171.5 + 2.35 × 1.5 = **175.03**
- 目標二：171.5 + 2.35 × 3.0 = **178.55**

這樣的設計確保每一筆交易的潛在獲利至少是潛在虧損的 1.5 倍。

---

**Q：買賣比是什麼意思？**

A：買賣比 = 當時委買總量（前五檔）÷ 委賣總量（前五檔）。

- 買賣比 > 1.5：買盤比賣盤多 50%，市場上有較多人在排隊買進
- 買賣比 ≈ 1.0：多空力量相當
- 買賣比 < 0.67：賣盤比買盤多 50%，賣壓較重

> 買賣比只反映**當下掛單狀況**，隨時會變，僅作短線參考，非決定性指標。

---

**Q：盤後還能使用嗎？**

A：可以。盤後系統顯示的是收盤價與當日最終的技術狀態。
均線、KDJ、RSI 等都是以歷史收盤價計算，盤後查看完全有效，適合做隔日的操作規劃。
即時的量比、買賣比資料在收盤後會停止更新，顯示當日收盤時的最終數值。
